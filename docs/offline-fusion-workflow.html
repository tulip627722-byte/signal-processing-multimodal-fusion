Depth + MID-70 + ADT7880 点云融合：执行手册

目标：从真实采集开始，生成完整处理结果、自动/手动标定、离线融合，最后用 MATLAB view_take 打开四窗口检查。

统一坐标约定：最终统一到 ADT7880 毫米波雷达坐标系：X=右，Y=前，Z=上，单位米。原始雷达点不会被“吸附”到板面；板面约束点和三路融合点会单独显示。
1

准备并启动采集程序

PowerShell：采集电脑执行

确保 ADT7880、Astra 深度相机、Livox MID-70 已连接；在采集程序中点击“安装位置…”填写当前安装关系，然后保存。

cd E:\leida\radar-camera-alignment\capture\app .\build.ps1 .\bin\Acquire.exe

GUI 中选择 ADC 直连、Orbbec Astra、Livox MID-70，设置时长后点击“开始采集”。take 目录必须有 radar_adc.mat、meta.json、深度 PNG、lidar\*.bin 和时间轴。

2

采集后先做数据验收

MATLAB Command Window
cd('E:\leida\radar-camera-alignment\matlab'); addpath('lidar'); takeDir = 'E:\leida\radar-camera-alignment\capture\takes\你的take目录'; report = inspect_lidar_radar_take(takeDir);

检查 LiDAR 文件数量、LIVOXBIN 版本、毫米波帧数、丢包和最近帧时间差。三路不完整就重新采集。

3

生成雷达 / Depth 处理结果

MATLAB Command Window

单个 take：

cd('E:\leida\radar-camera-alignment\matlab'); addpath(genpath(pwd)); [resFile, summary] = compute_take(takeDir);

多个 take：

compute_all([], struct('root', 'E:\leida\radar-camera-alignment\capture\takes'));

成功标志：生成 results\takes\<take名>_res.mat。

4

安装位置改变时重新标定

MATLAB Command Window；标定期间设备保持固定

先在采集程序“安装位置…”保存快照；准备至少 5 组静止棋盘/高反射板数据，覆盖左、右、上、下、近、远。

cd('E:\leida\radar-camera-alignment\matlab'); addpath('lidar'); config = lidar_radar_calibration_config(); config.takeNames = ["take_01"; "take_02"; "take_03"; "take_04"; "take_05"]; report = run_lidar_radar_auto_calibration(config);

只使用输出中 applicable=true 的候选外参；候选写入带时间戳目录，不覆盖正式 JSON。

5

导出 MID-70 原始点云（可选）

PowerShell：需要 PLY 时执行
cd E:\leida\radar-camera-alignment\capture\app .\export-lidar.ps1 -TakeDirectory "完整take目录" -Merged

输出在 take 下的 lidar_cloud；此步骤不代替 MATLAB 时间配对和融合。

6

生成离线三模态融合文件

MATLAB Command Window
cd('E:\leida\radar-camera-alignment\matlab'); addpath(genpath(pwd)); fusionReport = run_offline_fusion(takeDir);

输出 *_offline_fusion.mat、PLY 和质量 JSON。重点看 fusionReport.quality.status、radarBoardStatus、depthLidarStatus。

7

用 view_take 最终查看

MATLAB Command Window

推荐传入第 3 步结果文件：

view_take(resFile);

也可以直接传 take 目录：

view_take(takeDir);

显式指定外参和 LiDAR 时间窗：

view_take(resFile, 'lidarWindowMs', 1000, ... 'lidarExtrinsicsFile', '候选外参JSON完整路径');

四窗口验收：深度、MID-70 原生点云、毫米波点云、统一 ADT7880 坐标的三路融合。

“load_offline_fusion 无法识别”确认当前 MATLAB 路径是本仓库的 matlab，执行 addpath(genpath('E:\leida\radar-camera-alignment\matlab'))。
融合文件找不到先运行第 6 步，检查同名 *_offline_fusion.mat 是否生成。
雷达点不在板面先看质量报告和距离/角度偏差，不要移动原始点；必要时补采多姿态并重新标定。
最终交付保留原始 take、_res.mat、_offline_fusion.mat、质量 JSON、候选外参和截图。
