## 30 分钟预览压力测试

测试命令：

```powershell
Acquire.exe --preview-stress-test --seconds 1800
```

实测结果：

| 项目 | 结果 |
|---|---:|
| 持续时间 | `1800.1 s` |
| 发布 / 消费 | `162991 / 68967` |
| 预览覆盖率 | `57.6842%` |
| P95 发布到消费延迟 | `78.082 ms` |
| 进程退出 / 错误输出 | `0 / 空` |

长测期间进程正常退出且没有错误输出，说明最新帧单槽在持续覆盖下可以稳定运行。覆盖表示 10 Hz 消费端主动跳过相机等高频源的旧预览，不代表原始采集丢帧。P95 `78.082 ms` 高于 30 FPS 下两个帧周期约 `66.7 ms` 的阶段目标，因此延迟目标仍标记为待优化；该测试不写原始 ADC，也不替代四路真机落盘压力测试。
