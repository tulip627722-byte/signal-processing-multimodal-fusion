# 毫米波雷达-相机多模态融合（ADT7880 + Orbbec 相机）

信号处理课课设：完成毫米波雷达与相机的时间对齐、空间标定与融合验证。

## 当前进度

| 层级 | 状态 | 说明 |
|---|---|---|
| 时间对齐 | ✅ 完成 | 软同步逐帧配对（`frame_mapping.json`），雷达 499 帧 ↔ 相机帧 1:1，时间差 ±16.7 ms 内 |
| 相机内参 | ✅ 定稿 | 7×7 棋盘格，58 张有效图，2 阶畸变模型，平均重投影 0.12 px |
| 静态外参 R, t | ✅ 已求出 | 6 组静态姿态，RANSAC + LM，内点平均误差 ≈ 1.6 px |
| XYZ 验证 | ⏳ 下一步 | 点云投影叠加验证，见 [docs/04_XYZ验证方案.md](docs/04_XYZ验证方案.md) |
| 融合应用 | ⏳ 待做 | 依赖 XYZ 验证通过 |

> ⚠️ 已知隐患：静态标定点集中在单一空间位置，外参存在深度退化可能（Z_cam≈7.4 m vs 实际 ~2 m），必须经全场点云叠加验证后才能用于融合。

## 标定链快速开始（MATLAB）

前置：老师点云处理链与 CFAR mex 需在本地（见 docs/01 第「ADC 解析」节）。

```matlab
cd('E:\xinhaochuli\code')
export_radar_camera_pairs        % 1) ADC → 雷达 XYZ + 配对图
pick_static_pose_correspondences % 2) 每组姿态点一次对应点
estimate_extrinsic_from_pairs    % 3) RANSAC+LM 拟合外参，输出残差
```

详细步骤：[docs/02_静态外参采集执行步骤.md](docs/02_静态外参采集执行步骤.md)

## 关键约定

- 雷达坐标系：+X 向右、+Y 向前、+Z 向上，单位米
- 内参（第二轮定稿）：

```text
K = [967.2475      0       682.6840
         0    972.6627    354.9921
         0         0          1]
D = [-0.0806255410, -1.8604978506, -0.0021282179, 0.0217471697]  % [k1 k2 p1 p2]
```

- 外参：`results/extrinsic_calibration_static.mat`（`R`、`t`、`K`、`D`、`fitInfo`）
