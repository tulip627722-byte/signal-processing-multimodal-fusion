# 静态外参采集 · 执行步骤（一组 = 一个静止姿态）

## 采集前

1. 雷达和相机相对位置**固定**，全程不要再挪。
2. 共同目标：棋盘格朝向相机，板上/旁放**强反射体**（角反或金属片）。
3. 每个姿态：摆好后**静止 1–2 秒**再点采集；换近/中/远、左/中/右、略高/略低。
4. 建议 **12–20 组**（每组一个动作/姿态）。人不要在画面里走。

文件会进：`E:\xinhaochuli\savedata\`（ADC / Camera / Sync）。

---

## MATLAB 里按顺序跑

先：

```matlab
cd('E:\xinhaochuli\code')
```

### 0）（可选）指定本次会话

编辑 `static_calib_config.m`：

```matlab
cfg.sessions = {'20261021_150001','20261021_150130'}; % 改成你的前缀
```

留空 `{}` 则导出时自动发现「有 ADC+映射+视频、但还没导出配对」的会话。

### 1）导出雷达 XYZ + 配对图

```matlab
export_radar_camera_pairs
```

- 调用老师点云链，写出 `radar_camera_pairs\<会话>\`
- 同时生成 `static_pose_suggestion.json`（自动推荐稳定雷达点）

### 2）每组只点一次图像

```matlab
pick_static_pose_correspondences
```

- 左图：点**板中心**（全程统一）
- 右图：直接**回车**采用红星推荐点；或左键改选；右键跳过该组
- 汇总文件：`radar_camera_pairs\all_static_pose_correspondences.csv`

### 3）拟合外参（RANSAC 剔点 + LM）

```matlab
estimate_extrinsic_from_pairs
```

看：

- `radar_camera_pairs\extrinsic_calibration_static.mat`（`R,t`）
- `extrinsic_fit_residuals_static.csv`（`inlier` 列）

课设可用：内点平均误差 **&lt; 10 px** 且 `calibrationValid=true`。  
更严：&lt; 5 px。

若无效：删掉残差很大的会话行，或重采该姿态，再跑步骤 3。

## 相对旧流程改了什么

| 旧 | 新（静态） |
|----|------------|
| 一组里点 25 帧，易点飘 | **一组一点**，用整段稳定中位数 |
| 人工在散点里猜 | **自动推荐**高强度、低抖动 Track |
| 单次 LM | **RANSAC + LM**，输出内点 |
| 门限 5 px 一刀切 | 课设 10 px + 严格 5 px 两档 |

旧脚本 `annotate_extrinsic_pairs.m` 仍保留，静态标定请用新流程。

---

## 合格后再做什么

用 `extrinsic_calibration_static.mat` 里的 `R,t` 做投影叠加；不要用旧的 `calibrationValid=false` 结果。
